📚 CodeNotes – Programming Learning Website

CodeNotes is a responsive programming learning website designed for students and beginners. It provides a simple and interactive platform to explore programming topics and improve coding knowledge.

✨ Features

- 📱 Responsive design for mobile and desktop
- 🌙 Dark mode
- 📖 Programming topics with interactive modals
- 🧠 Interactive quiz
- ❓ FAQ accordion section
- 📩 Contact form with validation
- 📱 Mobile navigation menu
- 🔗 Smooth scrolling navigation

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

CodeNotes

│

├── index.html

├── style.css

├── script.js

└── README.md


🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Explore the CodeNotes website.

🎯 Project Objective

The main objective of CodeNotes is to make programming education simple, accessible and interactive for students and beginners.
